# Kiro

> **Category:** AI Coding Assistant | **Pricing:** Paid SaaS / preview availability varies | **Type:** Agentic IDE

Kiro is an agentic development environment from AWS that emphasizes spec-driven software work and structured implementation flows.

## When To Use

- Use Kiro when you want AI coding organized around specs, tasks, and implementation plans.
- Reach for it when teams need more process structure than free-form chat-driven coding.
- Consider it for AWS-heavy projects where cloud-native integration and enterprise controls matter.

## Practical Tips

- Write the spec before asking for implementation.
- Keep acceptance criteria concrete and testable.
- Use Kiro's task breakdown as a planning aid, then verify with local tests and code review.
- Treat it as a structured coding environment, not only an autocomplete tool.

## Watch Outs

- Spec-driven workflows still need human product judgment; a complete task list can still encode the wrong goal.
- Check cloud/account permissions before letting agents interact with infrastructure.
- Avoid committing generated code without security and dependency review.
