# OpenCode

> **Category:** AI Coding Assistant | **Pricing:** Free OSS client; model/API costs vary | **Type:** Open-source terminal coding agent

OpenCode is a terminal-first coding agent that emphasizes open workflows, model flexibility, and direct repository editing.

## When To Use

- Use OpenCode when you want a lightweight terminal coding agent without adopting a full IDE fork.
- Reach for it in command-line-heavy development environments and remote machines.
- Consider it when you want model/provider choice and scriptable agent workflows.

## Practical Tips

- Keep tasks narrow and commit frequently.
- Give the agent exact commands for tests, formatting, and type checks.
- Use separate worktrees for risky autonomous changes.
- Prefer read-only exploration before edits on unfamiliar codebases.

## Watch Outs

- Terminal-native agents can make broad changes quickly; review patches before staging.
- Tool availability varies by machine, so document expected commands in repo guidance.
- Avoid letting agent sessions mutate production credentials or deploy targets.
