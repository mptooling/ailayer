## Summary

Windsurf (rebranded from Codeium in late 2024) is an AI-native IDE built around the "Cascade" multi-step agent system. Cascade goes beyond autocomplete: it plans multi-step tasks, reads terminal output, runs tests, and iterates until the goal is reached — more like an autonomous agent than a code completion tool. Windsurf offers a generous free tier with no hard daily limits, making it popular with individual developers and startups. The Enterprise version supports self-hosted deployment with SOC 2 compliance, appealing to security-conscious IT teams. In 2026 benchmarks, Windsurf's Cascade leads in agentic task completion.

**Best for:** Developers wanting autonomous multi-step coding agents; enterprises needing self-hosted AI coding tools.

## AI Agents That Can Use This Tool

| Agent / Framework | How it integrates |
|---|---|
| **Claude** | Windsurf supports Claude models as the backbone of Cascade; users can select Claude Sonnet or Opus |
| **GPT-4 / o1** | OpenAI models power Cascade's reasoning and planning steps |
| **LangChain** | Can be called from LangChain agents via Windsurf's API (Enterprise tier) |
| **n8n** | n8n can trigger Windsurf tasks via REST API calls |
| **CrewAI** | CrewAI can delegate code tasks to Windsurf's Cascade agent via API |
