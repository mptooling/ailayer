# Langfuse

> **Category:** Evals & Observability | **Pricing:** Free OSS + paid cloud | **Type:** Open-source LLM observability platform

Langfuse is an open-source observability, prompt management, and evaluation platform for LLM applications.

## When To Use

- Use Langfuse when you want open-source tracing and prompt/version management.
- Reach for it when self-hosting and data control are important.
- Consider it for product teams that need to connect traces, scores, prompts, and user feedback.

## Practical Tips

- Version prompts and model settings alongside application releases.
- Capture user feedback and human review labels as eval data.
- Add custom scores for business-specific quality metrics.
- Use sessions to understand multi-turn conversations, not just single calls.

## Watch Outs

- Observability storage can grow quickly; define retention early.
- Prompt management is not a substitute for code review and tests.
- Redact sensitive data before exporting traces.
