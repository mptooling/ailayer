# Contributing

This repository is a Markdown library. Add or update entries by editing the relevant top-level `README.md` and the matching row in `INDEX.md`.

## Entry Checklist

- The entry has a clear category metadata block.
- The first paragraph explains the tool, skill, or tip in plain language.
- `When To Use` gives concrete situations.
- `Practical Tips` contains actionable guidance.
- `Watch Outs` captures limits, risks, pricing, or common mistakes.
- Links point to official docs or source repositories where possible.

## Recommended Superpowers Workflow

Use Superpowers for process discipline when the change is larger than a single entry:

- Start with `brainstorming` when the scope or audience is unclear.
- Write a plan with `writing-plans` before broad catalog restructures.
- Execute plans in small batches and verify links/searches after each batch.
- Use `verification-before-completion` before marking the change complete.

Small typo fixes and one-entry updates do not need a full plan.

## What Not To Add

- Injector code
- Generated prompt files
- Tool-specific installation automation
- Stale marketplace expansion plans
