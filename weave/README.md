# W&B Weave

> **Category:** Evals & Observability | **Pricing:** Free tier + paid Weights & Biases plans | **Type:** LLM tracing and evaluation toolkit

W&B Weave is Weights & Biases' toolkit for tracing, evaluating, and iterating on LLM applications and agents.

## When To Use

- Use Weave when your team already uses Weights & Biases for ML experiment tracking.
- Reach for it when you need lineage from datasets and prompts to traces and eval scores.
- Consider it for teams combining traditional ML workflows with LLM apps.

## Practical Tips

- Track inputs, outputs, model versions, prompts, and eval scores together.
- Use Weave objects to make experiments reproducible.
- Compare model and prompt variants against the same dataset.
- Connect offline evals to production examples.

## Watch Outs

- Avoid mixing exploratory notebooks and production traces without naming conventions.
- Make sure logged examples comply with privacy requirements.
- Do not treat aggregate scores as a replacement for reviewing failure clusters.
